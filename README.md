# Bird Jump Game

This was a small game I made back in highschool (2022 I believe). I made this since I learned that web browsers could load local files, and that I could program a game on my locked down Chromebook by simply editing a text file and running it through the browser. I was also able to host a web server and use my domain so that others could play without the school blocking the site.

The code is uploaded partly for portfolio, as well as to reminisce on things. All code and assets are made by me!

## Neo

Some changes I have made were some formatting, and I added an icon by grabbing a sprite and putting the sky gradient over it! On the itch page, I have to discard any weird formatting so that its just the canvas. Code will be somewhat changed!

## How to Play

You can either:
- Git clone this project, and then display the index.html file in your browser like so: `file://path/to/index.html`
- Play it on my Itch.io page [here](https://skrunkgy.itch.io/bird-jump-game).
